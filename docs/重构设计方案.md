# 幸存兔开发设计与后续计划

更新：2026-11-04。本文是唯一设计文档，区分当前0.2 demo和后续目标。当前源码与README是已实现行为的依据；标为后续或待做的内容尚未完成。

## 1. 最新决定与一致性规则

- 一局固定8波，前7波结束进入商店，第8波必须击败坏老板才获胜。局内不设置经验、角色等级或升级三选一；成长来自波后购买和局外成长树。
- 第1–2波草地、3–4波树林、5–6波沙滩、7–8波海里；WorldBackdrop摆放离线地面与点缀，海里显示游鱼、苹果泡泡和Boss下沉吐泡泡。沙滩/海里树分别使用矮棕榈/珊瑚苹果树，草地不叠方格线。
- 不提供手动难度选择。Profile v2的threatLevel为0–4，新档或缺字段为0，不从旧bossWins推断；通关+1封4，失败/主动结束不变。每波开始按威胁与当前构筑记录难度快照，波内不追涨。
- 自然结束奖励抵达波次×5积分，通关额外+10，主动结束0；局外攻击、生存、灵巧三枝各3节点，有前置与有限rank。购买立即保存，下次出发生效。
- 四组选角为课代饼、三好兔、饼狗、兔狗组合；组合包含心好兔与信号狗，共五个形态，不使用通用占位角色。
- 五张正式头像基于用户原始参考图，通过内置ImageGen直接生成“只有头部”的像素图；不裁切全身、不抠原图、不代码重绘。正式资源仅public/assets/characters下的classrep、goodrabbit、bingo、heart、signal五张透明PNG，选角/战斗/跟班/界面共用。
- 道具、敌人与环境使用脚本离线生成的PNG图集，浏览器只加载。角色不强制适配帽子等挂件，饰品属性和背包仍有效。
- 默认自动索敌/开火，设置可切手动。PC鼠标瞄准、按住左键连射；手机左摇杆移动，按住右摇杆连射并拖动瞄准，松开/取消停止。
- 普攻冷却与装填仅显示于角色头顶；技能与切换CD只用进度条不示数。HUD生命与护盾独立，树、桶、跟班和Boss有世界血条。
- 普攻、技能和跟班使用统一AttackMods快照，按相应机制继承伤害、暴击、双发、穿透及击杀效果。近战可挥掉普通敌弹；预警激光/区域独立判伤且不可格挡。
- 技能第5波起强化。苹果双环基础施放每圈32向、两圈64弹，强化单枚系数从0.85升至1.05；双发可追加较弱施放。
- 文字、字号、行高、控件尺寸和面板使用全局token；主次按钮同尺寸，仅语义色不同，紧凑与i按钮统一44px，弹窗共用动作区。
- 玩家文案不堆开发功能清单、版本完成度或路线图。规则进入玩法指南、当前决策和i详情，设置说明紧跟设置；实现进度写在README和本文。

## 3. 当前结构与职责

```text
src/game/types.ts       纯玩法定义和运行状态
src/game/content.ts     静态内容注册表与边界校验
src/game/Session.ts     一局状态、战斗、波后交易与胜败结算
src/game/MetaProgress.ts Profile v2、节点状态/购买、存档规范化与成长加成
src/main.ts             App装配、存档、设置、键鼠与双摇杆输入
src/WorldScene.ts       Phaser世界显示、血条、预警、相机与效果
src/WorldBackdrop.ts    四种biome地面、点缀与海底动效
src/DetailsView.ts      按内容和实时状态生成i详情
src/ShopView.ts         商品收益、价格与购买状态
src/MetaView.ts         成长树、前置/等级/积分与购买入口
src/style.css           全局视觉token、响应式控件与面板
src/audio.ts            程序化音效
art/sprites.mjs         道具、敌人与环境像素源
art/characters/prompts.json 正式头像提示词及生成来源
scripts/               离线素材准备、音乐制作与玩法/资源检查
public/assets/         PNG、图集JSON与manifest
public/fonts/          本地中文像素字体与许可
archive/               独立旧版归档
```

App创建并拥有Session，WorldScene通过host读取同一会话，DOM界面只调用动作。Session不依赖Phaser或DOM；表现读取结果，不重复结算伤害、货币和购买。胜败结果与积分只提交一次，重开创建新会话。

MetaProgress提供createProfile、normalizeProfile、getTalentState、buyTalent与成长加成收集；不直接操作DOM或localStorage。App负责读取/规范化和保存Profile v2，MetaView读取同一目录与节点状态；购买成功立即保存，下次Session取得成长快照。

Session当前集中部分战斗、生成和流程逻辑。职责确实拥挤时再依次提取攻击/伤害、敌人行为和库存交易；不为形式拆成十几层服务，不让旧入口与新入口双重结算。

## 4. 注册表、状态与扩展约定

采用静态TypeScript记录与直接导入；定义只读，Session保存可变状态。不引入运行时插件、反射扫描、表达式语言或通用ECS。types.ts和content.ts是字段契约的唯一来源，文档不复制另一套完整接口。

| 注册表 | 内容 | 消费方 |
| --- | --- | --- |
| characters | 名称、形态、基础属性、初始/形态技能、近战属性 | 选角、详情、会话 |
| enemies | 名称、贴图、HP/伤害/速度/半径、掉币、行为 | 生成与战斗；敌人详情/图鉴待做 |
| items | equipment/consumable、价格、层数、属性/效果、action、取得限制、可选外观 | 商店、背包、取得/使用、详情 |
| abilities | 名称、图标、描述、CD与行为 | 技能、操作按钮、详情 |
| talents/talentBranches | 分枝、固定费用、maxRank、前置、属性/效果 | MetaProgress、MetaView、成长详情 |
| cosmetics | 名称、素材、视觉槽 | 当前仅元数据，穿戴未实现 |
| stages | 8波的biome、时长、补怪间隔、HP缩放、奖励与敌人权重 | 有限波次与最后Boss目标 |

内容ID稳定，不随展示名或文件名改变，登记键与定义id必须一致。注册不等于自动进入所有商店/波次，资格、上限和权重仍须明确。

### 接入操作

| 新增项 | 必要改动 | 不应修改 |
| --- | --- | --- |
| 属性饰品 | 登记价格、上限、statBonuses/effectBonuses、图标 | 商店/背包/详情的具体ID分支 |
| 同AI敌人变种 | 登记EnemyDef并配置波次权重、离线素材 | UI和主流程 |
| 成长节点 | 登记分枝、前置、费用、maxRank、加成 | 购买事务、成长页布局 |
| 已有能力的新角色 | 登记角色/形态/能力与静态头像 | 选角布局和输入 |
| 全新AI/技能 | 新增必要行为实现与定义引用 | 其他角色的代码与UI |
| 装扮 | 穿戴实施时新增CosmeticDef与素材 | 不靠显隐改变属性 |

相同行为真实复用时再提取小工厂表；角色成长、跟班与切换暂保留少量清楚的专属规则，不能承诺任意新玩法只改JSON。props、掉落、武器表按实际需求提取。

### 状态与事务

- 生命、冷却、弹匣、库存、余额、波次和成长快照归本局，不写回定义。Profile v2保存统计、talentPoints、talents与threatLevel。
- 被动持有量是层数来源；一次性道具由槽位保存，成功使用消耗、失败不消耗。acquired是累计取得量，灯用完或切形态不清零。
- 商店验证商品批次、售出状态、余额与库存限制后统一提交；UI不先扣币。满槽替换仍待做，未来须共用先选择再提交的接收入口，取消不扣币/记取得/标售出。
- 角色冷却和兔狗共享状态不在HUD另存；移动、界面重绘和切换不重置。攻击、持续效果与治疗使用战斗时间，暂停/商店停止推进。
- 波初难度快照只计算一次，波内拾币、受伤和效果变化不追涨敌人。
- Boss击败、胜败结果、成长积分和统计只结算一次；主动结束为独立reason且不发积分。重开不残留旧局攻击、监听或计时。

## 5. 操作、战斗与收益规则

### 输入与显示

默认autoAim开启。关闭后PC传入鼠标方向和左键按住状态；手机右摇杆按住连续请求开火，拖动更新瞄准，释放/取消停止。鼠标与触屏held状态独立，左摇杆独占自身触点。失焦、取消和横竖屏改变时清空输入并暂停，避免粘连。

菜单、商店和成长页支持点击/触摸与键盘选择确认。视口使用可用宽高与RESIZE，世界坐标、相机、布局分开。普攻/装填条在头顶，技能/切换条在按钮；生命、护盾独立，树/桶/跟班/Boss始终有世界血条，Boss另保留顶部条。

首页和结果页进入成长，节点i共用详情，关闭后恢复成长页滚动位置。style.css按token→controls→menu→modal/details/settings/shop→HUD→motion→断点组织；同级文字使用共享字号/字重/行高，主次按钮48px，紧凑/i按钮44px，弹窗共用modal-actions。

### 装备与技能

- 远程普通弹最多3发，穿透最多额外2目标；近战最多3段，后续段65%伤害。近战每层穿透增加1个目标与8范围，每段最多3目标。
- AttackMods在起手记录damage、critChance、shotCount、pierce、explosionChance和lifesteal，弹丸、连段与技能使用该快照。一般技能双发最多追加两次45%威力施放，心好兔冲锋将双发/穿透转为接触命中预算。
- 近战120°扇区可挥掉普通敌弹，也占该段目标额度；激光/区域为独立hazard，预警后判伤且不参与格挡。激光预警0.9秒，区域1.05秒。
- 第5波起强化技能并将技能CD乘0.82。苹果双环保持基础64弹，只增强单枚威力；装备追加施放另计。
- 爆炸不递归触发同类击杀爆炸；回血只认实际回复，满血拾取与补盾不伪造治疗。

### 波次、资源与角色

花朵是真实拾取物，不放同形不可采装饰。前7波时间结束，finishWave统一结算地上花/币、清理战场、发波奖与普通波成长并进入商店；回血苹果和未取得道具不自动入账。第8波必须击败Boss，倒计时结束不判胜；Boss死亡发奖励并结束本局，不再接第9波。

| 角色 | 当前规则 |
| --- | --- |
| 课代饼 | 每普通波后+3%伤害与1最大生命；每3普通波招募1名跟班，最多8活体。跟班固定45HP、独立位置和射击/受击计时，按自身节奏单发，基础伤害为玩家20%，继承暴击/穿透/击杀效果；可被接触、敌弹与危险区杀死，不自动复活。当前8波自然招募点为第3/6普通波后 |
| 三好兔 | 拾币+50%；每持有5币伤害+1%，最多+30%，消费后回落；技能5枚饼干外观弹仍按苹果攻击结算 |
| 饼狗 | 苹果近战，波初补22%最大生命的苹果盾，实际治疗缓慢补盾 |
| 心好兔/信号狗 | 共享生命/主技能CD；切换CD4秒，0.9秒55%加速＋0.45秒保护。心兔技能2.2秒加速/无敌冲锋；狗技能6枚环绕苹果，双发追加后最多18枚，每枚命中1＋穿透个目标后消耗、最多存在5.5秒 |

高级备用生命尚未实现。后续若加入，采用每局一次、部分生命复起和短暂保护，不重发道具或清空取得历史。

### 一次性道具与局外成长

地图与商店共用取得限制。新档1槽，前两次累计击败Boss各加1槽，最多3槽；容量不自动发物品，当前满槽不接收新品。灯每局最多取得1次，成功使用消耗物品，但11.2秒无敌状态继续存在，不因切换或物品移除撤销。

自然结束积分=抵达波次×5＋通关额外10：首波战败5、第7波战败35、第8波战败40、通关50；主动结束0，只提交一次。成长购买固定扣该节点每级费用，前置至少1级才能买后继；达到maxRank停止。全树535积分，购买影响下一局，与饰品共用属性/效果上限。

通关后threatLevel增加1、最高4；战败/主动结束不涨不降。同一威胁下反复卡关仍能积累积分，成长补偿仅吸收一小部分增益且有上限，因此买成长保留实际优势；不增加用时判定或自动降档。

| 分枝 | 节点顺序、每级费用与上限 |
| --- | --- |
| 攻击 | 苹果力量：伤害+6%，20积分×3级 → 轻快出手：攻速+4%，25×2 → 灵光一闪：暴击+3%，30×2 |
| 生存 | 好好吃饭：生命+8，20×3 → 小小护甲：护甲+1，25×3 → 暖暖恢复：恢复+0.15/s，30×2 |
| 灵巧 | 小步快跑：移速+3%，20×3 → 饼干磁力：拾取范围+20，25×2 → 穿心练习：穿透+1，60×1 |

局外成长树已经重建；独立图鉴、成就和收藏页面仍是后续功能。

## 6. 头像、离线素材与音乐

### 五张正式头像

身份依据为五人参考中的课代饼、三好兔、心好兔、信号狗及独立饼狗图；第五位饼哩未额外加入。

| 形态 | 固定辨识特征 |
| --- | --- |
| classrep / 课代饼 | 深色短发、红框眼镜、人耳与脸颊细节 |
| goodrabbit / 三好兔 | 奶黄长耳、额头两笔、慵懒眼神 |
| bingo / 饼狗 | 白色垂耳、红苹果帽、顶部绿叶 |
| heart / 心好兔 | 白粉长耳、粉色额毛及额毛小红心 |
| signal / 信号狗 | 白粉垂耳、粉色额毛、耳部Wi-Fi标记 |

五个独立ImageGen请求明确HEAD-ONLY，提示词和文件ID在art/characters/prompts.json。prepare-character-images.mjs只整体等比缩为512×512、保留透明，不裁图或重绘；PNG入库，CI不调用生成服务。extract-characters.mjs仅整理参考，默认输出.verify/reference-cutouts，不生成正式头像或进入构建。

### 图集与音乐

art/sprites.mjs → scripts/build-assets.mjs → public/assets/atlas.png、atlas.json、manifest.json，开发/CI离线执行。资源路径统一解析部署base，兼容/RabbitSurvivor/；本地中文像素字体保留许可。纯外观不改变碰撞/数值，装扮选择与佩戴恢复时仍需独立视觉数据。

BGM为public/audio/orchard-futurebass.mp3，由scripts/build-music.mjs读取归档原曲离线制作。FFmpeg atempo=1.25保持音高，估计120→150 BPM；原旋律主体11.025kHz采样保持＋8bit量化，湿/干92%/8%，配future bass和弦/低音/侧链与鼓组。成品76个完整小节、121.6秒，最新编码约−16.14 LUFS、−1.73dBTP。

成品MP3直接入库，浏览器/CI不合成；只有重新制作时本地需要FFmpeg/ffprobe。参数和测量在art/audio/remix.json，说明在art/audio/README.md，开发中间文件留.verify不发布。边界已去点击，实际听感仍需试听评估；音乐加载或解锁失败不阻止开局。

当前波初评分：输出分包含相对基础伤害增量、0.35×攻速增量、0.3×额外发数、0.12×穿透；防御分为0.4×生命相对增量＋0.04×额外护甲。growthHp=1＋min(0.2,0.06×输出分＋0.02×防御分)，growthDamage=1＋min(0.08,0.04×防御分)，再乘上表威胁系数；机制tier=min(2,threatLevel＋floor(输出分/1.2))。各相对增量不取负，波内不重新计算。

检查新档与满成长、0/多饰品、近战/远程和手机路线，确保有限补偿仍保留成长收益。专测多重＋穿透＋爆炸、护甲＋恢复＋盾、经济＋持币增伤；检查灯对Boss战的影响与跟班死亡。记录实际伤害/受伤/收益和Boss击败时间，不用纯模拟宣称真人通关率。
